# Avatars

35 memoji-style faces (`memo_1.png` … `memo_35.png`) vendored from
[alohe/avatars](https://github.com/alohe/avatars) — MIT, see `LICENSE.txt`.

These are Apple-*style* originals, not Apple's own Memoji assets (which are
copyrighted and not redistributable).

Assignment lives in `lib/avatars.ts`: sellers own 1–9 (written into
`data/people.json`, one each), reviewers hash into 10–35 by handle.
